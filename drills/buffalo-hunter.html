Buffalo Hunter

A sharks-and-minnows style running game, built around passing accuracy for the coaches "hunting" on the sides.

Setup

  • Set up two lines of cones facing each other, forming a lane the kids will run across.
  • Coaches line up outside the cones on both sides, each with a ball to pass.

How to play

  1. Kids line up at one end of the lane, without a ball.
  2. On "go," the kids run from one end of the lane to the other.
  3. As they run through, the coaches on the sidelines pass balls at the runners, trying to touch them.
  4. Any kid touched by a ball is "out" — they join the coaches on the sideline for the next round.
  5. Repeat each round: more and more kids move from running to passing on the sidelines, while fewer remain running through the middle.

Coaching tips

  • Start with only coaches passing so the first round or two isn't too hard, then let the game snowball as more kids join the sidelines.
  • Great for passing accuracy on the sideline and change-of-direction / acceleration for the runners.
  • Keep the lane width adjustable — narrow it if runners are getting through too easily.
